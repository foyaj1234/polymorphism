= বহুরূপ
একই নাম, ভিন্ন রূপ
পলিমরফিজম হচ্ছে OOP-এর এমন একটি বৈশিষ্ট্য, যেখানে একটি ফাংশন বা অবজেক্ট ভিন্ন ভিন্ন রূপে মূলত ফাংশনের আর্গুমেন্ট বা ফাংশন কলের উপর নির্ভর করে ভিন্ন ভিন্ন ফলাফল প্রদান করে।

সহজ ভাষায়: একই নামের একাধিক মেথড ভিন্ন ভিন্ন কাজ করাকে পলিমরফিজম বলে।

কোড উদাহরণ

⌨ প্রোগ্রাম উদাহরণ

নিচের Python প্রোগ্রামে Turtle এবং Animal — দুইটি ক্লাসেই run() মেথড রয়েছে, কিন্তু কাজ ভিন্ন।

polymorphism.py 
class Animal:
    def __init__(self, name):
        self.name = name

    def run(self):
        print(self.name + " was adopted.")
        print("running!")


class Turtle(Animal):        # Animal-কে inherit করে
    def run(self):             # Method Overriding
        print("running slowly!")


tim = Turtle("tim")
tim.run()                     # Turtle-এর run() কল হয়
▶ Output
running slowly!
⚠ মেথড ওভার-রাইডিং (Method Overriding): Turtle ক্লাসে Animal ক্লাসের run() মেথড পুনরায় সংজ্ঞায়িত করাকে মেথড ওভার-রাইডিং বলে। এটি Runtime Polymorphism-এর একটি উদাহরণ।

⬡ সুপার ও সাব ক্লাস

উপরের প্রোগ্রামে দুটি ক্লাসের মধ্যে Inheritance সম্পর্ক বিদ্যমান:

Animal
🔼 Super Class (Parent)
Turtle
🔽 Sub Class (Child)

Turtle ক্লাস Animal ক্লাসকে ইনহেরিট করে। কলের উপর নির্ভর করে নির্ধারিত হয় — কোন ক্লাসের run() মেথড এক্সিকিউট হবে। এটিই পলিমরফিজমের মূল ধারণা।
